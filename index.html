화면설명

진열페이지 메인

1

헤더

좌측 전체메뉴 클릭 시 어드민에 등록된 카테고리가 노출됩니다. 우측 제휴/제안 버튼 클릭 시 제휴/제안 페이지로 이동합니다.

2

메인 배너

어드민에서 등록한 배너가 노출되며, GIF 이미지 등록을 지원합니다. 배너가 여러 개일 경우 순차적으로 노출됩니다.

3

플렉스지 가입 유도

무료 가입하기 버튼 클릭 시 플렉스지 회원가입 페이지로 이동합니다.

4

채널 바로가기

업체의 홍보 채널로 이동합니다. 채널 종류와 링크는 어드민에서 설정합니다.

5

상품리스트

업체가 진열한 상품의 썸네일, 상품명, 가격이 노출됩니다. 상품명 검색이 가능하며, 기본순/가격순/신상품순 정렬 옵션을 제공합니다(정렬은 프로토타입에서 선택 상태만 시각적으로 표시).

6

업체소개

업체 로고, 업체명, 한 줄 소개문구와 함께 설립연도·주요 거래처 수·인증현황·취급 카테고리 수 등 핵심 정보가 노출됩니다. 회사소개서 다운로드 버튼 클릭 시 파일이 다운로드됩니다.

7

매뉴얼

어드민에서 등록한 매뉴얼 파일이 노출되며, 카드 클릭 시 파일이 다운로드됩니다. 매뉴얼은 여러 개 등록할 수 있습니다.

8

연락처

전화번호와 운영시간이 텍스트로 노출됩니다. 카카오톡 상담 버튼 클릭 시 카카오톡 채널 상담 페이지로 이동합니다.

9

플렉스지 가입 플로팅 버튼

스크롤 위치와 관계없이 항상 노출되며, 클릭 시 플렉스지 회원가입 페이지로 이동합니다.

1

카테고리 패널

어드민에서 등록한 카테고리 목록이 노출되며, 카테고리 선택 시 해당 카테고리 상품만 노출됩니다.

2

닫기

클릭 시 패널이 닫힙니다.
